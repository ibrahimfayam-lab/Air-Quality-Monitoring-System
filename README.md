# Air-Quality-Monitoring-System
This project measures gas concentration, temperature, and humidity in real time using an MQ sensor and DHT11. The data is displayed on an OLED screen, with LED indicators showing air quality levels (Good, Poor, Very Bad, Toxic). A buzzer alert is triggered when the air becomes unsafe
